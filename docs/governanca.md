# 🧠 Governança do Projeto — ERP QA Lab

## 🎯 Objetivo

Garantir consistência, qualidade e padronização no desenvolvimento e validação do sistema.

---

# 📏 Princípio Fundamental

Nada deve ser feito fora do padrão,
sem antes evoluir o padrão.

---

# 🔄 Fluxo de Decisão

1. Identificar necessidade
2. Verificar documentação existente
3. Caso não exista padrão:

   * Atualizar documentação
4. Executar seguindo o padrão definido

---

# ❌ Proibições

* Criar tarefas fora do padrão
* Criar bugs sem estrutura
* Realizar commits sem padrão
* Validar sem checklist
* Corrigir sem rastreabilidade

---

# ✅ Obrigações

* Seguir padrões definidos nos documentos
* Garantir rastreabilidade entre Jira e GitHub
* Documentar exceções antes de executar
* Validar toda entrega

---

# 🚀 Objetivo

Construir um ambiente profissional de engenharia de software baseado em processo, qualidade e rastreabilidade.
